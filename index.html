核心链路

一条消息进来，先过这四道关

每一条客户消息都按同一顺序处理：先看名单，再试关键词，然后查知识库并交给 AI；处理不了的进入人工接管。每个功能页，都是在这条链路上加一道可控的开关。

01

白名单

只处理名单里的好友与群。陌生号只累计过滤数，不回复，也不转写语音、下载文件。

02

关键词

命中关键词就按规则立即回复，可带语音、图片和本机文件，不必等模型生成。

03

知识库 + AI

检索知识库，带上会话记忆生成回复；图片、语音、文档都能进同一条模型链路。

04

人工接管

未命中、情绪差或点名找人时，通知管理员并暂停该会话，由人来接手。

01 / 监听

先决定听谁说话

私聊支持白名单和黑名单两种模式，名单用好友选择器直接勾选，不用手抄账号标识。名单外的人发再多，也只在首页累计「监听外已过滤」，不回复、不转写语音、不下载图片和文件。

  • 群聊有独立名单：只有勾选的群进入应答管线；可以只在被 @ 时回复。
  • 短时间连发先合并成一次处理；关键词在合并后、模型前判定，常见问题不排队。
  • 首触系统帧与寒暄可以按「不回」处理，避免把系统提示当成客户问题。
  • 群聊没 @ 也没命中关键词时，仍会跑一遍分诊，情绪异常不会漏。
白名单黑名单名单外降噪合并等待
02 / 关键词

命中关键词，不排队等模型

客户问价格、要资料、约上门，命中关键词就直接按预设话术回复。关键词判定先于 AI，模型忙或超时也不耽误常见问题。

  • 关键词列表支持搜索、就地编辑；每条回复可以带语音、图片和本机文件。
  • 群聊开了「仅在被 @ 时回复」时，没 @ 但命中关键词仍会回；要真 @ 提问人，另开「回复时 @ 提问成员」。
  • 未命中的问题继续走知识库与 AI，不会直接丢掉。
文字语音文件先于 AI
03 / AI 应答

文本、图片、语音，都走同一套模型

模型配置只有一个入口：Base URL、Key、模型名填齐即生效，Key 掩码显示，旁边就能点「测试可用性」。文本、图片、语音最后都汇到这套 OpenAI 兼容接口。

  • 图片先下载到临时目录再交多模态模型；语音在 V2 网关走 CDN（约 2 秒），失败回退本机微信库解密转写。
  • 客户发 PDF 直接交给模型；Word、Excel 在本机抽出文本再交给 AI；纯文本里的链接会尝试读网页正文 实验。
  • 知识库 0 命中或客户要最新信息时按需联网搜索 实验；判定、分诊、摘要调用不联网。
  • 回复可自动分句，切点按词句边界、不拆词；默认关闭，长回复拆成几条更自然。
  • 多份 Prompt 分开管理，默认.md 随时改；回复延迟、频控与合并另在「其他配置」「安全设置」里。
OpenAI 兼容多模态语音转写联网搜索自动分句
04 / 知识库

回答有出处，资料跟着走 实验

接上千问 AI 平台（DashScope）的云端 RAG：文档解析、切片、向量化都在云端完成，面板只填 Key、知识库 ID 和检索参数。AI 回复后，还能按触发词把本机资料一起发出去。

  • top_k、相似度阈值、Agent ID（重排序）可调；知识库页可以直接测试检索。
  • 0 命中的问题自动登记；人工三态核实、筛选、导出 CSV，再补回知识库。
  • 触发词表优先：客户问题原文命中触发词，就发对应本机文件，不要求知识库命中。
  • 文档投票兜底：没有触发词命中时，按知识库片段投票；需过阈值、领先悬殊差，同会话 30 分钟去重。
  • 关闭 / 影子 / 正式三档；影子档只记「本应发哪个文件」。
云端 RAG触发词表文档投票未命中闭环影子校准
05 / 好友

从通过好友，到把介绍讲完

好友申请可以自动通过，通过后立刻发第一条消息；打招呼可带语音、图片和文件，顺序固定为文字 → 语音 → 图片 → 文件。

  • 待处理申请留在队列里；自动通过开关关掉也不会丢。
  • 介绍序列拆成「板块 → 条目」：第一条在建档时发出；客户每回一句就接下一个板块，不回才按间隔往下讲。
  • 追问只在板块边界出现；连续几个板块没回应自动停；转人工或 AI 在途时整条挂起。
  • 只对新好友生效，存量客户不补发；话术、打招呼、关键词、知识库附件都支持点击/拖拽上传。
自动通过打招呼四件套板块序列四条刹车
06 / 群聊

群聊只回该回的那句

群聊有独立开关和独立名单：只有勾选的群才进入应答管线；可以只在被 @ 时回复，回复时真 @ 提问成员；新成员入群可发欢迎语。

  • 群聊与私聊共用同一套知识库、记忆与分诊规则。
  • 没 @ 也没关键词时仍跑分诊；进群欢迎受群聊总开关约束。
  • 群名单点刷新才重新拉取，避免频繁请求微信。
仅 @ 回复真 @新人欢迎独立名单
07 / 定时与语音

到点发消息，文字和语音都行

定时消息支持每天、每周、每月、仅一次；目标从微信好友或群聊里选，文字与语音至少填一项，都填时先发文字再发语音。

  • 到点自动触发，重启后任务仍在；定时启停可限定每天的运行时段（默认 08:00–23:00）。
  • 语音发送覆盖关键词、定时消息、自动打招呼、新好友介绍四个入口；浏览器把常见音频转成 24k 单声道 WAV，服务端再转 SILK。
  • V2 网关走 3010，V1 直接拒绝不发；上传后可试听、可移除。
  • 定时任务与定时启停互不干扰，改完保存即生效。
每日 / 每周 / 每月 / 一次定时启停24k WAV语音发送 · 实验
08 / 朋友圈

只点新动态，评论有分寸

按间隔刷新最新一页 → 逐条点赞 → 点赞后按各自间隔评论；点赞、评论是两个独立开关，发出去的内容当着所有好友可见。

  • 第一次刷新只登记不动手；之后只点新出现的动态，历史动态不补；需要时手动「补点这一页」。
  • 评论可随机混用预设话术与 AI 生成，比例可调；可要求动态至少多少字才评。
  • 间隔上再加 0~30% 抖动；连续 5 次失败这一支停摆，点「继续」恢复。
  • 关闭 / 影子 / 正式三档，独立于「启动/停止机器人」；影子档只记「本应赞/评哪一条」。
只点新动态预设 + AI每日上限失败停摆影子
09 / 分诊与接管

该 AI 回的回，该人接的接 实验

每条客户消息先独立判一次情绪与成交意向，不要求知识库 0 命中。情绪差或点名要人工 → 通知并暂停该会话；意向高 → 只通知，AI 继续回复。

  • 通知带最近上下文、客户原问题和 AI 草稿；接管窗口与同类通知冷却可调。
  • 未命中问题进入待核实清单，支持筛选、导出 CSV、标记已核实并补充知识库。
  • 私聊里人工手打的回复会经网关 out 回推写进记忆，AI 能接上这段对话；群聊刻意不记。
  • 首页「需要你处理」三张卡：未命中待核实、分诊待处理、暂停中的会话。
情绪意向挂起台账人工回复记账
10 / 记忆与转发

记忆写在同一处，消息搬到该去的地方

每个会话一份记忆文件；AI 的回复和客服手打的回复都写回同一份上下文，不会各说各话。自定义转发则把收到的消息按规则搬到指定会话。

  • 记忆：最大条数、AI 上下文条数、摘要触发阈值可调；旧对话自动摘要压缩，并提取长期事实。
  • 转发：按关键词、指定发送人或无差别搬运；目标可选好友或群聊。
  • 来源可以「先选群、再选成员」，挑到不是好友的群成员；转发可附带来源信息。
  • 转发统一走发送队列，受频控约束。
会话记忆摘要压缩关键词·发送人·无差别非好友群成员

设计取舍

这些细节，决定了它每天好不好用

不追求把 AI 能做的事都做一遍，而是把「发出去之前」和「发出去之后」都留好刹车与出口。

01

本机优先

配置、日志、会话记忆、备份都在本机；面板默认只监听 127.0.0.1，不把整段会话上传。

02

影子先行

会主动发消息、发文件、发语音、加好友、点赞评论的功能都有三档；先看日志校准，再切正式。

03

会刹车

频控、随机延迟、消息合并、同内容去重；连续无回应停发，连续失败停摆，不靠人盯着。

04

知识闭环

答不上来不是终点：登记、核实、补回知识库；资料还能跟着回复一起发，下次直接答。

05

人机共用记忆

AI 的回复和客服手打的回复写进同一份会话上下文，不会出现两套话术各说各话。

06

全链路语音

收语音能转写，发语音覆盖关键词、定时消息、自动打招呼、新好友介绍四个入口。

07

可诊断

启动自检 19 项、V1/V2 协议诊断、日志按「要不要人看」分层，内置操作教程与更新日志。

08

单文件交付

一个 exe 双击启动，配置热生效；端口被占用直接启动中止，不静默抢消息。

留在本机

config 配置、logs 日志、memory 会话记忆、backups 备份、attachments 附件；面板默认只监听 127.0.0.1。

发到云端

在本机完成

名单匹配、关键词、频控、定时调度、转发、记忆读写都在本机；模型接口若指向本机服务，文本与图片这一步也可以不出本机。

运行方式

先影子跑几天，再切正式

会发消息、发文件、发语音、加好友、点赞评论的功能都有三档。影子档只写运行日志，不碰客户。

关闭

完全不执行

功能停用，连影子日志也不写。适合还没想清楚要不要开的阶段。

影子

只判断，不发送

按真实节奏判断，只记录「本应做什么」，客户一条都收不到。建议先用这一档校准。

正式

命中就真发

消息、文件、语音、好友申请与朋友圈互动都按这一档执行，发出不可撤回。

  • 配置保存在本机 config 目录，面板里改，保存即生效。
  • 运行日志只显示需要人处理的行，详细记录写日志文件。
  • 单文件 exe，双击启动；配置、日志、记忆跟程序放在一起。
  • 内置操作教程与更新日志；版本号与更新日志同步。
